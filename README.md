# Formula Student Team Database UI

A frontend interface developed for the Oxford Brookes Formula Student team to manage and visualize operational data.

## Features
*   **Dynamic Sidebar:** Collapsible navigation sidebar for better screen space management.
*   **Light/Dark Mode:** User-toggleable theme for improved usability.

## Tech Stack
*   **Frontend:** React, JavaScript, HTML, CSS
  

## Project Context
This project was developed as part of my work with the Oxford Brookes Formula Student team (2024-2025). The team achieved 3rd place at Formula Student England.
